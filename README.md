# 敏捷测试项目

本目录是基于《报告.docx》和《报告.xlsx》整理的 Markdown 版本。Word 和 Excel 是本目录内容的依据；以下文件按主题拆分，内容与两份正式文件保持一致。

## 文件导航

- [测试计划](plan.md)：范围、环境、准入准出条件和风险记录。
- [用户故事](stories.md)：用户故事、验收标准、优先级及关联用例。
- [需求与测试用例追踪矩阵](trace.md)：需求、验收标准、用例、结果和缺陷的对应关系。
- [测试用例](test-cases.md)：20 条测试用例及其执行结果。
- [缺陷流转记录](bug-flow.md)：缺陷状态、流转示例和协作记录。
- [回归测试计划](regression.md)：P0/P1 回归范围、执行记录和结论。
- [测试总结](summary.md)：测试统计、缺陷状态和最终结论。

## 当前结论

登录、商品浏览、购物车和结算核心流程均已完成测试与回归检查。当前发现的 3 个缺陷仍处于 Open 状态，尚未完成修复和复测，因此当前版本不建议直接判定为完全通过；应在缺陷修复后再次执行相关 P0 和 P1 回归用例。
